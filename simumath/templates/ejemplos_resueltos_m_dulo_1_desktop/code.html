Ejemplo resuelto paso a paso

Resolveremos la ecuación f(x) = x³ − x − 2 = 0, cuya raíz real es x ≈ 1.5213797. Primero localizamos la raíz:

  • f(1) = 1³ − 1 − 2 = −2  y  f(2) = 2³ − 2 − 2 = 4
  • Como f(1) · f(2) = −8 < 0 y f es continua, por el Teorema de Bolzano existe al menos una raíz en el intervalo [1, 2].
