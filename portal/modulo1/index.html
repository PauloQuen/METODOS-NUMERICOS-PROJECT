Errores numéricos y tolerancia

Ninguna aproximación numérica es exacta. La pregunta clave no es ¿el resultado es exacto?, sino ¿el error está dentro de la tolerancia aceptable?. A continuación definimos los tres conceptos que usaremos como criterios de parada en los métodos iterativos.

Error absoluto

Ea = | x̄ − x |

Diferencia entre el valor aproximado x̄ y el valor real x, tomada en valor absoluto. Expresa cuánto nos equivocamos, en las mismas unidades de la variable.

Error relativo

Er = | x̄ − x | / | x |

Normaliza el error absoluto dividiendo entre el valor real (o el aproximado si el real es 0). Se suele expresar en porcentaje y permite comparar la calidad de aproximaciones de distinta magnitud.

Tolerancia

| xn+1 − xn | < tol

Umbral de error aceptable fijado por el usuario. Los métodos iterativos se detienen cuando la variación entre dos iteraciones consecutivas cae por debajo de la tolerancia.

Método de Bisección

La bisección encuentra una raíz de una función continua f a partir de un intervalo [a, b] donde la función cambia de signo.

  1. Verificar el teorema de Bolzano: si f es continua en [a, b] y f(a) · f(b) < 0, entonces existe al menos una raíz en el intervalo.
  2. Calcular el punto medio c = (a + b) / 2 y evaluar f(c).
  3. Reducir el intervalo: si f(a) · f(c) < 0, la raíz está en [a, c]; si no, en [c, b].
  4. Repetir hasta que la amplitud del intervalo o f(c) caiga por debajo de la tolerancia.
Convergencia: es siempre convergente si se cumple la condición de signo, pero converge lentamente (una forma lineal): cada iteración reduce el intervalo a la mitad. Para una tolerancia ε, el número de iteraciones necesarias es n ≥ log₂((b − a) / ε).

Método de Newton–Raphson

Newton linealiza la función en cada iteración usando la recta tangente: partiendo de una semilla x₀ cercana a la raíz, la siguiente aproximación es la intersección de la tangente con el eje X.

xn+1 = xn − f(xn) / f′(xn)

  1. Elegir un valor inicial x₀ razonablemente cercano a la raíz.
  2. Evaluar f(xₙ) y su derivada f′(xₙ).
  3. Actualizar con la fórmula de iteración.
  4. Detenerse cuando |xₙ₊₁ − xₙ| < tol, |f(xₙ)| < tol o se alcance maxIter.
Convergencia: es cuadrática cerca de la raíz (duplica cifras correctas por iteración), pero no siempre converge: falla si f′(xₙ) = 0 o si x₀ está lejos de la raíz. También equívoca el resultado si la raíz es múltiple.

  • f(1) = 1³ − 1 − 2 = −2  y  f(2) = 2³ − 2 − 2 = 4
  • Como f(1) · f(2) = −8 < 0 y f es continua, por Bolzano existe una raíz en [1, 2].

Autoevaluación y ejercicios

Resuelve cada ejercicio y luego desplega la solución para verificar. Recomendado: usa lápiz y papel antes de mirar la respuesta.

  1. Si el valor real es x = 10.5 y la aproximación es x̄ = 10.4, calcula el error absoluto y el error relativo.

    Mostrar solución

    Ea = |10.4 − 10.5| = 0.1.   Er = 0.1 / 10.5 ≈ 0.00952 (0.952 %).

  2. ¿Cuántas iteraciones de bisección se necesitan como mínimo en el intervalo [1, 2] para garantizar una tolerancia ε = 10⁻³?

    Mostrar solución

    n ≥ log₂((2 − 1) / 0.001) = log₂(1000) ≈ 9.97, por lo tanto n = 10 iteraciones (siempre se redondea hacia arriba).

  3. Justifica, usando el teorema de Bolzano, que f(x) = x³ − x − 2 tiene al menos una raíz en [1, 2].

    Mostrar solución

    f es polinómica, luego continua. f(1) = −2 y f(2) = 4. Como f(1)·f(2) = −8 < 0, existe c ∈ (1, 2) con f(c) = 0.

  4. Partiendo de x₀ = 1.5, aplica una iteración del método de Newton a f(x) = x³ − x − 2.

    Mostrar solución

    f(1.5) = −0.125 y f′(1.5) = 3(1.5²) − 1 = 5.75. Entonces x₁ = 1.5 − (−0.125 / 5.75) = 1.5 + 0.021739 ≈ 1.521739.

  5. ¿Por qué el método de Newton falla si f′(x₀) = 0?

    Mostrar solución

    La fórmula x₁ = x₀ − f(x₀)/f′(x₀) requiere dividir entre la derivada. Si f′(x₀) = 0, la tangente es horizontal, no corta el eje X y la división es por cero (indefinida o infinita).

  6. Concepto: si un método se detiene cuando la tolerancia es 10⁻⁶, ¿qué garantiza ese criterio?

    Mostrar solución

    Garantiza que la variación entre dos iteraciones consecutivas |xₙ₊₁ − xₙ| es menor a 0.000001, es decir, la aproximación ya no cambia de forma significativa. No garantiza por sí sola la exactitud contra el valor real; por eso conviene verificar también que |f(xₙ)| sea pequeño.
